# Project Brief: Student Landing Page Generator Workspace

## 🎯 Overarching Goal
This repository serves as a standard, modular **Git workspace template** for students (học viên) to systematically design, copywriting, code, and deploy high-converting landing pages following a structured **5-Step Workflow** in collaboration with AI coding assistants (e.g. Antigravity, Claude, Cursor).

---

## 🎨 Core Principles
1. **Student Self-Containment**: Every student project must reside strictly within a designated subfolder inside `projects/` (e.g. `projects/the-smile/`).
2. **Vanilla Static Stack**: Standard HTML5, CSS3, and ES6 Javascript. Absolutely zero compilation or build scripts, ensuring instant drag-and-drop deployment for absolute beginners.
3. **CRO Copywriting Focus**: Pages are structured around a conversion-optimized grid of **8 essential sections** (Navbar ➔ Hero ➔ Impact & Marquee ➔ Products Grid ➔ Proof ➔ About & Skills ➔ Blog Grid ➔ Lead Form with Web3Forms).
4. **Serverless Lead Capture**: Utilizes public environmental Web3Forms public API key configurations injected seamlessly.

---

## 📂 Key Architecture
- **`Skills/LandingPage_Skills.md`**: Master design patterns, color variable option pairs (Option A Dark / Option B Light), typography mood, and component guidelines.
- **`steps/`**: 5 sequential files guide students step-by-step from description intake to deployment.
- **`detail_spec.md`**: Complete technical specifications for the entire workspace.
- **`Readme.md`**: Engageable, student-facing Vietnamese manual containing quick copy-paste AI prompt cards.
- **`.agents/workflows/`**: Automation procedures for AI assistants to load and save workspace context.
